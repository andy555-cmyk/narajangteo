과업 정의

한국문화정보원이 이미 구축·운영 중인 실감형(VR/체험형) 시스템과 콘텐츠를 계속 유지·운영하는 사업이다. 공고문에는 계약조건·자격요건만 있고, 구체적 과업내용(세부 유지운영 범위, 장애대응 체계, 콘텐츠 업데이트 범위 등)이 담긴 제안요청서 원문은 확보되지 않아 세부 내용은 확인 필요 상태다. 제목과 자격요건(소프트웨어사업자 등록, 정보시스템유지관리서비스 직접생산증명서)으로 볼 때 신규 기획·설계가 아니라 기존 시스템의 운영·유지보수(SI 운영유지) 성격의 사업으로 판단된다.
  • 실감형 체험시스템(하드웨어·소프트웨어) 유지운영 — 세부 과업내용은 제안요청서 원문 미확보로 확인 필요
  • 콘텐츠 유지운영(업데이트·장애대응 등 추정) — 세부 과업내용은 제안요청서 원문 미확보로 확인 필요

평가 배점 (승부처)

구분평가항목배점
원문에 배점표 미기재 — 확인 필요. 공고문에는 '기술능력평가 90% + 가격평가 10%, 기술능력평가 배점한도 85% 이상 시 협상적격자 선정'이라는 종합평가 비율만 있고, 세부 평가항목·배점 테이블은 제안요청서(원문 미확보)에 있어 옮길 수 없음.
